# Agent docs and one version source: implementation plan

> For agentic workers: use superpowers:subagent-driven-development or executing-plans. One task per
> implementer session; `verify` skill before each commit. Branch `feat/agent-docs`, one PR at the end.

**Goal:** hull v0.12.1, splice 0.6.0, bosun 0.18.0; one machine doc for an agent in a TARGET repo,
committed (raw GitHub) and served (`/agents.md`, from `/llms.txt`); every version/command from one
source, a test fails when committed Markdown differs from the generator.

**Architecture:** `versions.ts` + `scenarios.ts` builders stay the data. Docs pages move to templates
in `apps/site/docs-src/` with `{{ks.*}}` tokens; `scripts/gen-docs.ts` (Node 24 strips types, as
`scripts/adopt.mjs` does) renders them to the committed `src/pages/docs/*.md` and root `agents/`.
`generated.test.ts` runs `gen-docs.ts --check`. No new deps. Committed output, not a remark plugin:
raw GitHub must show finished pages; output stays in `src/pages/docs/`, so routing and globs hold.

## Global constraints

- Token syntax `{{ks.NAME}}` only; anything else (e.g. `${{ secrets.X }}`) passes through untouched.
- Unknown token throws `gen-docs: unknown token {{ks.x}} in docs-src/<file>:<line>`.
- Generator output is run through `vp fmt` (tables re-align when a token changes width); `--check`
  renders + formats into a temp dir and diffs, so `format:check` and the drift test agree.
- `apps/site/tsconfig.json` gets `"allowImportingTsExtensions": true` (as packages/docspack has);
  only `versions.ts`, `scenarios.ts`, `render.ts`, `generate.ts` sit in the Node-run import graph.
- `apps/site/turbo.json` `test`/`build` inputs add `$TURBO_ROOT$/agents/**` (as docspack's turbo.json),
  so a hand edit to root `agents/` reruns the drift test.
- `astro build` never writes generated files (turbo runs build before test; writing would hide drift).
- Generated `.md` starts (after frontmatter) with `<!-- generated by scripts/gen-docs.ts from docs-src/<f>; edit that -->`;
  the shared frontmatter regex (docs-md.ts, start-md.ts, tests) strips it; never in `/docs/start/<id>.md`.
- Copy rules of `docs/agents/project.md` (no invented facts, `TODO(copy)`); no model or client names.

## Review focus

2. `${{ ... }}` in ci.md/releases.md survives rendering byte for byte.

4. Bump one version in `versions.ts` → every page, `/llms.txt`, `/agents.md`, `agents/versions.json` agree.
5. `agents/README.md` stays compact (≤ 10 KB) and every command block in it equals a builder output.

### Task 4: the agent doc

**Files:** create `docs-src/agents/README.md`, `src/pages/agents.md.ts`, `src/pages/agents/versions.json.ts`,
`src/data/agents.test.ts`; generated: root `agents/README.md`, `agents/versions.json`; modify `src/lib/llms.ts`,
`scenarios.ts` (`verifyBlock`, `rollbackBlock`), `packages/docspack/scripts/build.ts` (also pack `dist/agents.md`).
Step 0: a fact list in the test file's header, each fact citing its source at the pinned tag (hull
adopt.md / `hull.assess/1` fields, `bosun --help`, `splice --help`, `hoist --help`). Unverified →
`TODO(copy)` in the doc, never a guessed command (e.g. `splice check`, `hoist check` until seen in --help).
Structure of `agents/README.md` (agent reads it in full; terse, imperative):

1. Use: you are in the TARGET repo; versions line `{{ks.*}}`; bosun JSON contract (`next`, `error.fix`, exit codes).
2. Decide: empty/no commits → A (new). Existing → run `{{ks.block.adoptHullBlock}}` assess lines;
   `template` = template|template-rust → hull adopt (B); null → channels only (decisions channel;
   bosun only if `stack` ∈ rust|ts-pnpm). `.splice/` or `.bosun/version` present → upgrade (D). Mode
   change → C. Signals table = hull's `--assess` fields (link hull adopt.md table; do not copy).
3. Human-only checklist first (D-009): each item phone|computer + agent check command: create/push
   GitHub repo (`gh repo view`), Claude GitHub App, approve setup PR head + merge (`gh pr view --json state`),
   `hoist apply` with admin rights (`hoist check`), cloud env setup script paste (Start E), signer
   keygen enroll (`bosun doctor`). Owner batches approvals ("approve A B C").
4. Steps per path: numbered; each = command block (builder), verify (`pnpm run ci`, `bosun doctor`,
   `splice check`, `hoist check`), rollback (delete branch / close PR; `--dry-run` writes nothing;
   `bosun migrate --to <tighter>`).
5. Sources: raw GitHub URLs of `agents/README.md`, `/docs/start/<a-f>.md`, hull adopt.md at tag.

- [ ] Tests: every ```bash block equals some `block.*` (incl. verify/rollback); versions in `agents/versions.json` === `versions`;
