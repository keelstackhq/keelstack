# @keelstackhq/keel-darwin-x64

The keel binary for macOS x64. Installed by [`@keelstackhq/keel`](https://www.npmjs.com/package/@keelstackhq/keel)
as an optional dependency; do not depend on it directly.

```bash
npm install -g @keelstackhq/keel
```
