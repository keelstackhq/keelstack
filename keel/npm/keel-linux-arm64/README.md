# @keelstackhq/keel-linux-arm64

The keel binary for Linux arm64 (static musl). Installed by [`@keelstackhq/keel`](https://www.npmjs.com/package/@keelstackhq/keel)
as an optional dependency; do not depend on it directly.

```bash
npm install -g @keelstackhq/keel
```
