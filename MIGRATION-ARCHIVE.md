# Archive pointers for the old repos

Apply when each old repo is archived (D-023): replace its README.md with the text below, then
archive the repo. Do not change anything else there: archived repos stay cloneable, so pinned
old sources, actions and release downloads (versions up to 0.21.0) keep working.

## keelstackhq/bosun

```markdown
# bosun (archived)

This repository moved to [keelstackhq/keelstack](https://github.com/keelstackhq/keelstack/tree/main/bosun)
(folder `bosun/`, full history imported; decision D-023). Issues and PRs go there.

Releases after 0.21.0 are published from keelstackhq/keelstack: one tag `vX.Y.Z` for all tools.
Update references to: `gh:keelstackhq/keelstack//bosun/channel`.
Existing pins to this repository keep working; it is read-only.
```
