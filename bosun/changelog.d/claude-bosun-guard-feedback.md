- PreToolUse Bash guard: a glob is refused only where it can widen a git or command word (tests, regexes, file lists, `case` patterns and comments pass); a script is read only when the command runs it (shell operands parsed, data heredocs skipped), scripts run by scripts are read the same way, binaries are never read, and a script the same command writes is refused; brace text inside quotes passes; `git fetch` may join read-only commands.
