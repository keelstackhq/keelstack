- PreToolUse Bash guard: a glob is refused only where it can widen a git or command word (tests, regexes, file lists, `case` patterns and comments pass); a script is read only when the command runs it (shell operands parsed, data heredocs skipped), scripts run by scripts are read the same way, binaries are never read, and a script the same command writes is refused; brace text inside quotes passes; `git fetch` may join read-only commands. Round three: only a valid host ELF/Mach-O header with a NUL in its first line is a binary; a script run after a command that may write in the same call is refused; `cd`/`pushd`/`env -C` before a script are followed or refused; `case` arms and function bodies are judged; `\"` and `$'..'` quoting; variable command names, gh/git subcommands and aliases; fish, csh, pwsh, nu, xonsh, elvish, parallel, `make -f`, `find -exec {}` refused.
